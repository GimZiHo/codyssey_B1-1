# 포트폴리오 학습자료 작성 기준

Claude Code는 전역 CLAUDE.md의 학습자료 작성 기준을 따르고, 이 문서에서는 프로젝트별 적용 사항만 확인한다.

## 작성 범위

- Codex가 전달한 학습 개념과 관련 코드 위치를 바탕으로 설명 순서와 본문을 구성한다. 문단별 뼈대를 별도로 요구하지 않는다.
- DOM 조작·이벤트·비동기 처리에서는 사용자 입력부터 상태 변경과 화면 업데이트까지 실제 코드의 흐름을 설명한다.
- 사용자의 질문으로 드러난 설명 부족은 기존 개념 문서에 예시와 함께 보완한다. 새 개념이 아니면 별도 문서를 만들지 않는다.

## 검증 기록

- 브라우저에서 실행 절차와 상태·시간에 따른 변화를 확인하고, 명령·환경·실제 결과·미확인 항목을 기록한다.
- 구현 단계에서는 정지 화면을 캡처하지 않는다. 애니메이션 이해에 필요하면 GIF나 영상을 검토하되 필수 산출물로 만들지 않는다.
- 최종 제출용 스크린샷은 제출 단계의 과제 요구사항으로 별도 관리한다.

## 갱신 범위

- 개념 문서를 추가하면 `docs/learning/README.md`의 목록을 갱신한다.
- 작업 결과는 `docs/progress.md`의 해당 체크박스와 현재 상태에 반영한다.
- 루트 README는 사용자 요청이 있을 때만 읽기·검토·수정한다.
- Claude Code는 자료의 정확성과 링크를 확인하고 반영 여부를 완료 보고한다. Codex는 학습자료의 본문과 diff를 재검토하지 않는다.
