소개

라이브러리 없이 순수 HTML·CSS·JavaScript로 웹의 구조와 스타일, 동작을 직접 다루며 기초를 다지고 있습니다. 도구가 대신해 주던 부분을 직접 써 봐야 브라우저가 하는 일과 제 코드가 책임질 일을 구분할 수 있다고 생각해, 이 포트폴리오도 프레임워크 없이 처음부터 작성했습니다.

화면의 변화는 사용자 이벤트가 상태를 바꾸고 그 상태가 다시 화면에 반영되는 흐름이라고 이해하고 있습니다. 다크 모드 전환과 저장, GitHub API 요청의 로딩·성공·실패·빈 목록 상태, 문의 폼의 입력 검증과 오류·성공 안내를 모두 같은 흐름으로 구현했습니다.

기능을 하나 마칠 때마다 화면 크기와 조작 순서를 바꿔 가며 브라우저에서 직접 확인하고, 문제를 찾으면 원인과 고친 이유를 기록으로 남깁니다. 아직 배우는 단계지만 확인한 근거 위에서 코드를 꾸준히 개선하는 태도로 일하고 싶습니다.

학습 중인 기술

  • HTML — 콘텐츠의 의미와 구조 표현
  • CSS — 화면 배치와 스타일 구성
  • JavaScript — 사용자 이벤트와 화면 변화 연결
